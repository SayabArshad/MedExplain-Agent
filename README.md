[![License](https://img.shields.io/badge/License-Educational%20Use-lightgrey)](LICENSE)

**MedExplain** is an intelligent AI agent that helps patients, medical students, and clinicians understand laboratory test reports. It extracts test names and values from **plain text or PDF files**, compares them against a curated reference database (110+ biomarkers), classifies risk into **Low / Moderate / High**, and generates **compassionate, plain‑language explanations** using a large language model.

> ✅ Built with **Streamlit** + **Groq Llama-3.3-70B** (free tier)  
> ✅ Achieves **96% accuracy** on a 50‑case medical test set  
> ✅ Ready for academic submission (Assignment 2 – Methodology & Results)

## 🚀 Features

- 📝 **Two input modes** – paste text or upload a PDF lab report  
- 🧠 **LLM‑based extraction** – automatically recognises test names and numeric values  
- 📊 **110+ built‑in reference ranges** – haematology, chemistry, lipids, thyroid, cardiac markers, vitamins, hormones, urine tests  
- 🎯 **Rule‑based risk classification** – transparent, no LLM hallucinations  
- 💬 **Patient‑friendly explanations** – generated by Groq’s Llama‑3.3‑70B  
- 🎨 **Colour‑coded output** – 🔴 High Risk, 🟠 Moderate Risk, 🟢 Low Risk  
- ⚠️ **Medical disclaimer** – clearly states it is not a diagnostic tool  
- ⚡ **Fast response** – ~8.7 seconds per full report

## 🏗️ System Architecture (Agent Paradigm)

| Component | Implementation |
|-----------|----------------|
| **Brain** | Groq Llama‑3.3‑70B (free API, 30 req/min) |
| **Memory** | Embedded Python dictionary of reference ranges |
| **Perception** | PyPDF2 (PDF text extraction) + regex |
| **Action** | Rule‑based risk classifier + LLM explanation generator |
| **Interface** | Streamlit web application (medical theme) |

**Workflow:**  
1. User provides text or PDF  
2. Extract raw text  
3. LLM extracts test names + values (JSON)  
4. Look up reference range in memory  
5. Apply risk rules → Low / Moderate / High  
6. Generate explanation (LLM) and display formatted output

## 📖 Installation & Setup

### 1. Clone the repository
```bash
git clone https://github.com/yourusername/MedExplain-Agent.git
cd MedExplain-Agent
```
### 2. Create a virtual environment (recommended)
```bash
python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate         # Windows
```
### 3. Install dependencies
```bash
pip install -r requirements.txt
```
### 4. Get a free Groq API key

Sign up at console.groq.com

Go to API Keys → Create API Key

Copy the key (starts with gsk_)

### 5. Create a .env file in the project root
```bash
GROQ_API_KEY="gsk_your_key_here"
```

6. Run the application
```bash
streamlit run app.py
```
The app will open at http://localhost:8501 in your browser.

## 📊 Evaluation Summary
We evaluated MedExplain on 50 lab test cases (15 high‑risk, 20 moderate‑risk, 15 low‑risk) covering 15 different biomarkers, with ground truth provided by a practising physician.

Metric	Result
Accuracy	96% (48/50 correct)
Macro F1 score	0.96
Precision (High Risk)	1.00
Recall (High Risk)	1.00
Average response time	8.7 seconds
User satisfaction (1–5)	4.8 (clarity), 4.7 (trust)
Comparison with baselines:

Outperforms general ChatGPT (78% accuracy, hallucinations)

Outperforms rule‑only systems (no explanation)

Comparable to specialised lab‑AI systems but with free API and web interface

Detailed results and confusion matrices are available in the accompanying paper: AI_Assignment_02.pdf.
